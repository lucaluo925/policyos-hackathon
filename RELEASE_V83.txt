PolicyOS V83 — policy-event judge-flow repairs (14 October 2026)

BEHAVIOR
- Verification links carry a validated original source URL as unverified context.
  Copying a link or opening it in another tab no longer depends on the original
  tab's session storage. Empty/unsafe sources do not inherit stale context.
- Source context stays separate from retrieval evidence and model input. It is
  bound to the completed claim for report export, and can be cleared before
  the next check. Historical recordings do not acquire this current context.
- A failed refresh, including an unavailable-source response, retains previously
  loaded announcements for the same filters and explicitly labels the failure.
  Changing filters clears that batch rather than showing another country's rows.
- A source failure while loading an older page preserves the pagination cursor
  and retry control rather than silently ending the list.
- Event JSON includes the selected view, filters, loadedAt and latest read status.
  Saved browser snapshots have no invented collection time. CSV export failures
  now provide a retry message; both download paths attach their temporary link.
