# Public source scope

For the latest deployed source and access limits, see
[`RELEASE_V78.txt`](RELEASE_V78.txt). Historical checks below retain their
original dates and do not establish continuous availability.

This public repository was created from one clean source snapshot; it is not
the older Production deployment. It retains the full
functional PolicyOS application: live Tavily/Nemotron verification, its
evidence-trail report, the global directory, and the direct official-source
announcement reader. It includes 13 claim-only starters that require a fresh
provider-backed run, plus dated BOE and EU AI Act examples without provider
calls. The BOE example publishes all six of its adjudication passages. The
EU example publishes one unchanged passage out of seven and lists the six
withheld source URLs; it is not a complete public model-input archive.
The map can hand off any directory economy to the live claim verifier and can
initiate on-demand Tavily Search for climate, trade or immigration even where
no fixed source is configured. Its country-specific links are research leads,
not official feeds, verified in-force policies or pre-existing scores. A
PostgreSQL audit-log reservation provides a shared 60-call UTC-day ceiling
before paid map searches when a database is configured. A separate
Serializable reservation caps rolling-24-hour live verifier runs before
paid provider calls, including failed and disconnected attempts. Vercel
deployments require both shared reservations and fail closed without a
database. Neither application cap is a provider billing ceiling.
The final verification event and export distinguish a confirmed review-queue
write from a skipped or failed write. A review-storage failure does not make
the source-backed result disappear or silently claim that it was saved.

The candidate deliberately omits 13 old full recorded-example files, three
verifier seed recordings, and the `evaluations/` research packet directory.
The unmodified raw records remain in the private v24 archive, where their
original hashes and historical limitations can be checked. An older public
ZIP must not be presented as this source scope. The public
[`EVALUATION_SUMMARY.md`](EVALUATION_SUMMARY.md) reports selected-case outcomes
and failures but does not claim to recreate exact old model inputs. The
included BOE example is from a separate local v25 live run. It retains exact
adjudication inputs and omits earlier retrieval and screening passages, which
included other publishers' text. Its displayed tool counts are historical.

The four HTML parser fixtures are self-authored synthetic input, not captured
government pages. An unfrozen French backfill CSV is excluded. The production
code's on-demand external retrieval still follows each provider's terms.
Publisher URLs, document titles and dated metadata may appear in the source or
at runtime; the MIT license grants rights only to original PolicyOS material.

The current source has a 217-entry country/economy directory and a
self-hosted Natural Earth 1:50m map. Exactly 188 country outlines can select a
directory economy through an unambiguous point-in-polygon match; the other
outlines are visual context. This adds map selection, not policy-source or
score coverage. The optional country-government-site
Tavily mode is configured for 28 countries; these are search restrictions,
not 28 standing policy feeds. The source registry lists 23 jurisdictions with
configured feeds and 15 score profiles. On 13 October 2026 UTC, the protected
Preview's live database reported 13 source rows across 11 pipeline countries;
those live rows are a narrower operational measure. Four new configurations were tested with one
bounded call each: Saudi Arabia and Kenya returned no retained links for the
chosen topics, while the Philippines and Nigeria returned government-domain
research leads. The Philippines list exposed generic navigation pages, which
the current title filter excludes in an offline regression test. The dated
results and limits are in `EVALUATION_SUMMARY.md`; neither this development
packet nor a recognized government domain establishes legal status or
issuing-body identity.

The current candidate also reserves each hosted verifier run in a shared
rolling-24-hour audit-log limit before any paid provider call. Failed or
disconnected runs retain their reservation, and a missing or unavailable
database stops hosted verification before spending. Local key-only development
remains available without a database. This is an application admission limit,
not a provider billing ceiling or verified judging-period capacity.

The initial 335-file public source archive passed a fresh offline dependency
install, 487 tests, lint, type-check and a production build. Its one-commit
public release also passed GitHub CI. A bounded source-rights review found no
World Monitor code or assets in the release
tree. A [protected Preview run](PREVIEW_ACCEPTANCE.md) exercised the hosted
Tavily/Nemotron path and review storage; browser visual acceptance of the later
map changes, unrestricted judging access and provider capacity for the judging
period remain open before hackathon submission. The package
contains no right to use a third party's trademark in the required public
video.
